# Wi-Fi Connector

Небольшое приложение для Android (API 21+), которое подключает телефон к одной сохранённой
сети Wi-Fi при открытии выбранного приложения. Если определение активного приложения на
телефоне недоступно, дополнительный постоянный режим подключается всякий раз, когда
настроенная сеть находится в зоне действия.

Это личное приложение для ручной установки. Оно не публикуется в Google Play и не связано
с Spotify. Spotify (`com.spotify.music`) — лишь приложение-триггер по умолчанию; вместо него
можно выбрать любое установленное приложение.

## Что делает приложение

- **Триггер по приложению (основной режим):** служба доступности отслеживает смену
  активного приложения. Когда выбранное приложение выходит на передний план, приложение
  сохраняет/активирует настроенную сеть Wi-Fi и подключается к ней. Приложение-триггер
  выбирается из списка установленных приложений на главном экране (по умолчанию Spotify).
- **Резервный режим постоянного подключения:** foreground-служба следит за результатами
  сканирования Wi-Fi и просит Android подключиться, когда настроенный SSID виден. Она также
  перезапускается после перезагрузки.
- **Ручная проверка:** на главном экране можно подключиться сразу и посмотреть статус и журнал.

Служба доступности проверяет только имя пакета активного приложения. Она **не** читает
содержимое экрана, тексты, пароли и уведомления.

## Требования

- Android 5.0 (API 21) или новее.
- Приложение, которое будет триггером, установлено на телефоне.
- Разрешение на определение местоположения (нужно Android для сканирования Wi-Fi).
- Включённые службы определения местоположения для резервного режима.
- На Android 13+ разрешение на уведомления для уведомления foreground-службы.

## Сборка

Проект использует Gradle 8.7 и Android Gradle Plugin 8.5.2. Нужны JDK 17 и Android SDK
Platform 34 / Build Tools 34.

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```

APK создаётся здесь:

```text
app/build/outputs/apk/debug/app-universal-debug.apk
```

Установите его через ADB или скопируйте APK на телефон:

```bash
adb install -r app/build/outputs/apk/debug/app-universal-debug.apk
```

Если файл `local.properties` отсутствует, создайте его с путём к SDK:

```properties
sdk.dir=/path/to/android-sdk
```

## Первичная настройка

1. Откройте приложение.
2. Введите **SSID** и пароль сети Wi-Fi.
3. Выберите тип безопасности:
   - `WPA/WPA2` для обычных домашних сетей и точек доступа телефона.
   - `Open` для сети без пароля.
   - `WPA3` только на Android 10+.
4. В разделе **Приложение-триггер** нажмите **Выбрать приложение** и выберите приложение,
   которое должно запускать подключение. По умолчанию это Spotify; при желании выберите другое.
5. Нажмите **Предоставить разрешения на местоположение и уведомления** и разрешите запросы.
6. Нажмите **Включить обнаружение приложения**, затем включите **Wi-Fi Connector** в разделе
   Android «Настройки» > «Специальные возможности».
7. При необходимости включите **Всегда подключаться, когда сеть в зоне действия**.
8. Нажмите **Сохранить и подключить** один раз, чтобы проверить подключение.
9. Включите Wi-Fi и службы определения местоположения. Откройте приложение-триггер; в журнале
   должен появиться соответствующий пункт.

На Android 11+ доступна кнопка **Добавить сеть через диалог Android**, которая позволяет
подтвердить сеть через системный интерфейс Android. Это полезно, если производитель телефона
блокирует устаревшие API Wi-Fi.

## Как работает подключение

Android менял API Wi-Fi со временем, поэтому приложение использует два пути:

| Версия Android | Путь |
| --- | --- |
| 5.0-9 (API 21-28) | `WifiManager.addNetwork()` + `enableNetwork()` |
| 10+ (API 29+) | Устаревший путь всё равно используется, потому что приложение нацелено на SDK 28. Если производитель его блокирует, приложение добавляет `WifiNetworkSuggestion`, и подключение выполняет Android. |

Приложение намеренно использует `targetSdk 28`. Приложения с targetSdk Android 10 (API 29)
и выше не могут пользоваться устаревшими API `addNetwork()` / `setWifiEnabled()`. Цель 28
позволяет немедленному подключению работать на многих устройствах с Android 10-14. Плата за
это — несоответствие требованиям Google Play для новых публикаций; устанавливайте вручную
для личного использования.

Определение активного приложения использует службу доступности без фильтра `packageNames`,
так как приложение-триггер настраивается. Служба получает события смены окон для всех
приложений и реагирует только тогда, когда пакет события совпадает с сохранённым
пакетом-триггером.

## Хранение пароля

Пароль Wi-Fi хранится в отдельном файле настроек `secrets`, отдельно от остальных настроек,
и шифруется ключом, который не покидает Android Keystore:

- **Android 6.0+ (API 23+):** AES/GCM.
- **Android 5.0-5.1 (API 21-22):** RSA (на этих версиях Keystore не поддерживает
  симметричные ключи).

Если шифрование недоступно, приложение пишет предупреждение в журнал и оставляет значение в
отдельном файле секретов, чтобы приложение продолжало работать. Пароль, сохранённый в
открытом виде старой версией, автоматически переносится в зашифрованное хранилище при первом
чтении.

## Локализация

Интерфейс доступен на английском и русском языках. Русские строки находятся в
`app/src/main/res/values-ru/strings.xml`.

## Ограничения

- **Android не гарантирует незаметное переключение Wi-Fi.** На Android 10+ некоторые
  устройства требуют однократного подтверждения предложенной сети. Приложение запишет это
  в журнал и сможет открыть диалог подтверждения Android.
- **Службу доступности нужно включать вручную.** Android не позволяет приложениям выдавать
  её самим. Если она отключена, используйте резервный режим или включите её заново.
- **Приложение-триггер должно быть на переднем плане.** Имя пакета настраивается и по
  умолчанию равно `com.spotify.music`.
- **Резервный режим чувствителен к расходу батареи.** Android может ограничивать фоновое
  сканирование или останавливать службу. Отключите оптимизацию батареи для приложения, если
  служба останавливается. Служба использует уведомление с низким приоритетом и опрос раз в
  60 секунд.
- **Для сканирования Wi-Fi на большинстве версий Android должны быть включены службы
  определения местоположения**, хотя приложение не использует ваше местоположение.
- **Некоторые оболочки производителей** блокируют `addNetwork`, `setWifiEnabled` или события
  доступности. Приложение записывает ошибку в журнал и по возможности переходит к предложениям
  сети.

## Устранение неполадок

- **«Обнаружение приложения: ВЫКЛ»**: включите службу доступности и держите флажок
  включённым. На Android 13+ приложению, установленному вручную, может мешать «Ограниченный
  доступ»; откройте Android «Настройки» > «Приложения» > «Wi-Fi Connector» > меню >
  **Разрешить ограниченные настройки**, затем снова включите службу доступности.
- **«Разрешение на местоположение отсутствует»**: нажмите кнопку разрешений и разрешите
  определение местоположения.
- **«Wi-Fi выключен, и приложению не разрешено его включать»**: включите Wi-Fi вручную,
  затем нажмите «Сохранить и подключить».
- **Сеть видна, но подключения нет**: проверьте пароль и тип безопасности или используйте
  **Добавить сеть через диалог Android** на Android 11+. Если вы ранее отклонили предложенную
  сеть, Android мог отозвать у приложения разрешение на управление Wi-Fi; выдайте его снова в
  разделе «Настройки» > «Приложения» > «Специальный доступ» > «Управление Wi-Fi».
- **Служба останавливается через некоторое время**: отключите оптимизацию батареи для
  приложения и убедитесь, что уведомления разрешены.
- **При открытии приложения-триггера ничего не происходит**: откройте приложение ещё раз
  после включения службы; события доступности приходят при смене окон. Проверьте журнал
  приложения на запись «Selected app opened» и убедитесь, что выбранное приложение совпадает
  с сохранённым.

## Структура проекта

```text

  SpotifyAccessibilityService.java    обнаружение выбранного приложения на переднем плане
  WifiAutoConnectService.java         необязательный постоянный наблюдатель сканирования

app/src/main/res/values/strings.xml

```
